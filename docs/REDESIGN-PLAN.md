## 2. IA(정보 구조) 개편

```
현재: 홈 / 소개 / 블로그 / 포트폴리오 / 강의 / 학급 / 연락처  (7개)
변경: 홈 / 소개 / 포트폴리오 / 문의                          (4개)
```

- **삭제 라우트**: `/lectures`, `/classroom`(+notices, meals), `/blog`(+[slug]) — 파일·컴포넌트·타입까지 제거
- **원페이지 지향**: 항목이 적으므로 홈에 소개·포트폴리오 프리뷰를 충실히 넣고, 상세는 개별 페이지
- 문의는 "강의·컨설팅 문의"가 아닌 **"편하게 인사·의견·협업 아이디어 나눠요"** 톤

## 3. 콘텐츠 재구성 (새 서사)

**핵심 포지셔닝**: "교실 14년의 교사가, AI와 함께 1년 만에 학급 경제 SaaS를 만들다"
— 허세 없는 진짜 스토리가 곧 차별점. 목업 실적보다 강력함.

- **홈 히어로**: 새 서사 헤드라인 + CTA(알찬 보기 / 문의하기)
- **소개 타임라인**: 2012 교직 시작(14년 역산) → 에듀테크 관심 → 2025 바이브코딩 시작 → 2026 알찬 운영 중 *(연도는 사용자 확인 필요 — 아래 §6)*

- **문의**: 이메일 카드(215253422+iw-lab@users.noreply.github.com) + 심플 폼(이름·이메일·내용 3필드) → Firestore 저장

## 4. 디자인 방향 3안 (프리뷰 = docs/design-preview.html)

| | A안 Aurora Dark ⭐추천 | B안 Editorial Light | C안 Vivid Friendly |
|---|---|---|---|
| 무드 | 다크 기본, 오로라 그라데이션 메시, 글래스 카드, 글로우 | 라이트, 큰 디스플레이 타입, 무채+포인트1색, 벤토 그리드 | 밝은 고채도, 그라데이션 CTA, 친근한 교육 무드 |
| primary | 바이올렛→시안 그라데이션 (`262 83% 58%` → `189 94% 43%`) | 무채 + 인디고 accent (`239 84% 67%`) | 스카이 (`199 89% 48%`) + 앰버 accent |
| radius | 1rem (글래스 카드) | 0.25rem (샤프) | 0.75rem |
| 유행 요소 | aurora blob·glassmorphism·gradient text·noise texture·스크롤 리빌 | bento grid·oversized type·마이크로 인터랙션 | 부드러운 그라데이션·이모지 절제 사용 |
| 성격 | "세련+화려" 요구에 정확히 부합, 개발자 포트폴리오 대세 | 차분·지적, 화려함은 약함 | 현행과 유사 계열, 교사 정체성 강조 |

**추천 = A안**: "요즘 최신 유행 + 세련 + 화려" 요구와 가장 일치. 다크 기본 + 라이트 토글 유지.

## 5. 기술 계획

- 스택 유지: Next.js 15 + Tailwind + framer-motion + Firebase (변경 없음)
- D2: 토큰 3계층(primitives→semantics→다크) `globals.css` CSS 변수로 재정의, hex 직접 사용 금지
- D4: 히어로 aurora 배경(CSS gradient blob + blur, JS 无), 스크롤 리빌(framer-motion `whileInView`), 벤토 그리드 소개 섹션
- 문의 폼: `submitContactForm()` 실연결 + 에러 처리, firestore.rules에 contacts create 허용 확인
- 삭제: lectures/classroom/blog 라우트, schoolApi.ts(급식 API), Notice 관련 코드, testimonials/lectures 데이터
- D5 게이트: design-gate FAIL 0 → 스크린샷 3종(라이트/다크/모바일) 비전 검수 → 교차검증 LITE
